# Merchant Cashflow Desk

An open-source adaptation for Aayushi’s product portfolio.

## Provenance
Forked from [tuanpham-dev/react-invoice-generator](https://github.com/tuanpham-dev/react-invoice-generator), released under the MIT licence. The invoice editor and PDF export belong to the upstream project and contributors. The original LICENSE is retained.

## Current status
The reusable invoice/PDF foundation has been added to this account. Deployment and merchant workflow enhancements are not complete. No live deployment is claimed.

## Planned adaptation
- Track invoice due dates and manually recorded paid/unpaid status.
- Show outstanding and overdue amounts with explicit calculation rules.
- Keep fictional sample invoices separate from user-entered records.
- Connect the collection overview to the existing invoice/PDF editor.

This is a demonstration, with no payment collection, bank connection, automated reconciliation, tax-compliance certification or customer adoption claims.

## Development
See package.json for the current scripts and dependencies. Validate a production build and PDF export before publishing.
